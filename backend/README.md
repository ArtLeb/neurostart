# НЕЙРОСТАРТ — backend

Серверная часть: Hono, tRPC, Drizzle ORM и MySQL. Каталоги `backend` и `frontend` должны лежать рядом: frontend использует типы API из `backend/api/router.ts` только во время проверки TypeScript.

## Подготовка

Требуются Node.js 22+ и MySQL 8+.

```bash
cd backend
npm ci
cp .env.example .env
```

Заполните в `.env`:

- `APP_ID` — идентификатор приложения, например `neurostart`;
- `APP_SECRET` — случайная секретная строка длиной не менее 32 символов;
- `DATABASE_URL` — строка подключения MySQL;
- `PUBLIC_APP_URL` — публичный адрес сайта без завершающего `/`;
- `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` — серверные ключи магазина ЮKassa;
- `YOOKASSA_VAT_CODE` — код НДС для чека, значение необходимо подтвердить по настройкам магазина и налогообложения.

Не переносите ключи ЮKassa во frontend и не публикуйте `.env`.

## База данных

### Новая пустая база

```bash
npm run db:push
npm run db:seed
```

### Обновление исходной базы

Сначала сделайте резервную копию. Затем один раз выполните `database/001_update_from_original.sql` для базы, созданной исходным `schema.sql`:

```bash
mysql -u USER -p < database/001_update_from_original.sql
mysql -u USER -p < database/002_add_referral_rewards.sql
npm run db:seed
```

Первый скрипт рассчитан на базу `neurostart`; при другом имени измените строки `CREATE DATABASE` и `USE`. Он сохраняет старые реферальные таблицы и `lesson_videos`, добавляет тесты, попытки, доступы и платёжные события. Не запускайте его повторно и не применяйте к базе, уже созданной по новой схеме. Второй скрипт добавляет реферальные награды и подарочный доступ; его можно повторить после прерванного запуска.

Seed идемпотентно добавляет два начальных курса, восемь уроков и сорок вопросов. Первый зарегистрированный пользователь получает роль администратора, последующие — роль ученика.

## Запуск для разработки

```bash
npm run dev
```

API слушает порт `3000`. Frontend для разработки запускается отдельно на порту `5173` и проксирует `/api` на backend.

## Проверка и production

```bash
npm run check
npm run build
```

После сборки backend скопируйте содержимое собранного frontend в `backend/dist/public` и запустите сервер из каталога `backend`:

```bash
npm start
```

Полная последовательность сборки двух частей из общего родительского каталога:

```bash
cd frontend && npm ci && npm run check && npm run build
cd ../backend && npm ci && npm run check && npm run build
rm -rf dist/public
cp -R ../frontend/dist dist/public
npm start
```

Для production нужен HTTPS: сессионная cookie помечается `Secure` в production-режиме.

## Реферальная программа

Регистрация принимает необязательный `referralCode`. Первая успешная оплата приглашённого переводит его связь в `qualified`; повторные покупки того же пользователя не увеличивают счётчик. За каждые 10 оплативших создаётся отдельная награда. Её можно один раз обменять на опубликованный платный курс с `allow_as_gift = true`, если доступ к нему ещё не выдан. Подарок сохраняется в `course_access` с источником `gift`.

## ЮKassa

Поддерживаются способы `bank_card` и `sbp`. В личном кабинете ЮKassa укажите webhook:

```text
https://ВАШ-ДОМЕН/api/payments/yookassa/webhook
```

Сервер повторно запрашивает статус платежа у ЮKassa перед выдачей доступа. Без ключей магазина создание платежа отключено; тестовая или локальная оплата не имитируется.
