# НЕЙРОСТАРТ — frontend

Интерфейс на React, TypeScript и Vite: каталог курсов, личный кабинет, видеоуроки, тесты с проходным баллом 80%, оплата, реферальные награды и админка. На главной есть блок «10 друзей — курс в подарок!», а в `/my#referral` — персональная ссылка, статистика приглашённых и выбор подарочного курса.

Каталог `frontend` должен находиться рядом с каталогом `backend`: проверка типов использует `AppRouter` из backend. В собранный JavaScript серверный код не попадает.

## Разработка

Сначала настройте и запустите backend на порту `3000`. Затем:

```bash
cd frontend
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Vite проксирует запросы `/api` на `http://localhost:3000`.

## Проверка и сборка

```bash
npm run check
npm run build
```

Готовые статические файлы появятся в `frontend/dist`. Для единого production-запуска скопируйте эту папку целиком в `backend/dist/public`, затем выполните `npm start` в backend.

Медиафайлы из `frontend/public`, включая `videos/neurostart-intro.mp4`, автоматически попадают в сборку.
